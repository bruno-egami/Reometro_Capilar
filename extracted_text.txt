Este documento consolida três análises técnicas independentes realizadas sobre o sistema de reometria capilar: uma revisão de código (11 issues identificadas), uma verificação dos cálculos físicos e modelos e um levantamento de oportunidades de melhoria de precisão (10 melhorias propostas). O resultado é um mapa completo do estado atual do sistema e um plano de ação priorizado por impacto.

4. Correções Detalhadas
4.1  [🔴 Alta]  Inconsistência de chave MODELS vs PARAM_NAMES_MAP
Arquivo: modelos_reologicos.py
O dicionário MODELS registra o modelo com a chave 'Lei de Potencia' (sem acento), enquanto PARAM_NAMES_MAP usa 'Lei da Potência' (com acento e cedilha). Qualquer código que itere MODELS e consulte PARAM_NAMES_MAP pelo mesmo nome retornará None silenciosamente ou lançará KeyError.
# Estado atual — INCORRETO
MODELS = {
    "Lei de Potencia": (model_power_law, ...),   # sem acento
}
PARAM_NAMES_MAP = {
    "Lei da Potência": [...],                    # com acento
}
# Correção — unificar com acento em ambos os dicionários
MODELS = {
    "Lei da Potência": (model_power_law, ["K", "n"], ...),
}
PARAM_NAMES_MAP = {
    "Lei da Potência": ["K (Pa.s^n)", "n (-)"],
}
# Verificar também reologia_fitting.py:
# if best_model_nome == "Lei de Potencia":   ← atualizar para "Lei da Potência"
4.2  [🟡 Média]  Import no final do arquivo
Arquivo: modelos_reologicos.py · linha 153
A linha from scipy.stats import linregress aparece após todas as definições de função, violando PEP 8 e mascarando dependências. Mover para o topo do arquivo junto aos outros imports.
4.3  [🟡 Média]  Race condition no loop de leitura serial
Arquivo: reometer_controller.py · _read_loop()
O código envia READ_VOLTAGE a cada iteração, mas só executa readline() se in_waiting > 0. Respostas tardias do Arduino acumulam na fila e são descartadas, causando leituras desatualizadas. A solução é sempre ler após escrever, confiando no timeout da porta serial:
# Atual — condicional incorreto
self.ser.write(b'READ_VOLTAGE\n')
if self.ser.in_waiting > 0:           # problema: descarta resposta tardia
    line = self.ser.readline()
# Correto — sempre lê após escrever
self.ser.write(b'READ_VOLTAGE\n')
self.ser.flush()
line = self.ser.readline().decode('utf-8', 'ignore').strip()
if not line:
    continue

4.5  [🟡 Média]  Exceção silenciosa no ajuste de modelos
Arquivo: reologia_fitting.py · linhas 55-58
O bloco except Exception: pass descarta qualquer falha de ajuste sem registro. Substituir por logging.warning para facilitar diagnóstico:
import logging

A variável L_R_target_list armazena razões L/D (comprimento/diâmetro), não L/R como o nome indica. Renomear para L_D_target_list. O cálculo em si está correto — trata-se apenas de nomenclatura enganosa.

6. Qual Pressão Usar para τ_w?
O código calcula delta_p = p_linha − p_pasta mas usa p_pasta no cálculo de τ_w. Isso é fisicamente correto, confirmado pelo firmware do Arduino:
Sensor
Nome no código
Posição física (firmware)
Sensor 1 (A0)
p_linha_bar
Transdutor do Barril — pressão pneumática do pistão
Sensor 2 (A1)
p_pasta_bar
Transdutor da Entrada do Capilar (Membrana Aflorante) — P na entrada do capilar
O Sensor 2 mede diretamente a pressão na entrada do capilar. Com saída à pressão atmosférica (P_gauge = 0): ΔP_capilar = p_pasta. Portanto τ_w = (p_pasta × R)/(2L) está correto.
O delta_p = p_linha − p_pasta representa perdas mecânicas na câmara/barril (atrito, inércia). É calculado e armazenado no analysis_data, mas não exibido nos relatórios — ver Melhoria M10 na Parte III.

M2 — Detecção Automática de Regime Estacionário
Problema: a coleta atual calcula a média simples de toda a série temporal entre INICIAR e PARAR, incluindo o transiente de extrusão inicial (a pasta leva alguns segundos para estabilizar). Em simulações, o transiente causa erro de ~8% na pressão média.
Solução: ao parar, analisar a série e selecionar automaticamente a janela de menor coeficiente de variação (CV = std/mean):
def detectar_regime_estacionario(pressoes, fs=10, janela_s=3.0):
    n_janela = int(janela_s * fs)
    melhor_cv, melhor_inicio = np.inf, 0
    for i in range(len(pressoes) - n_janela):
        w = pressoes[i:i + n_janela]
        cv = np.std(w) / np.mean(w) if np.mean(w) > 0 else np.inf
        if cv < melhor_cv:
            melhor_cv, melhor_inicio = cv, i
    return melhor_inicio, melhor_cv
# Em save_point():
idx_start, cv = detectar_regime_estacionario(self.p2_data)
p2_estavel = self.p2_data[idx_start:]
p2_avg = np.mean(p2_estavel)
UX: destacar graficamente a janela selecionada (região colorida no gráfico de coleta). Permitir que o usuário ajuste manualmente a janela antes de confirmar o ponto.
Impacto verificado: P média com transiente: 5,406 bar (erro 8,1%). Com detecção automática: 5,007 bar (erro 0,1%).

M3 — Weissenberg-Rabinowitsch com n' Local
Problema: n' global subestima o fator W-R nas extremidades da curva (erro até 15% para fluidos HB — ver §8).
Implementação:
def weissenberg_rabinowitsch_local(gd_app_mean, tau_mean):
    if len(gd_app_mean) < 3:  # fallback global
        slope, *_ = linregress(np.log(gd_app_mean), np.log(tau_mean))
        n_g = float(np.clip(slope, 0.05, 3.0))
        return gd_app_mean * (3*n_g+1)/(4*n_g), n_g, None
    n_local = np.gradient(np.log(tau_mean), np.log(gd_app_mean))
    n_local = np.clip(n_local, 0.05, 3.0)
    gd_true = gd_app_mean * (3*n_local+1)/(4*n_local)
    n_global, *_ = linregress(np.log(gd_app_mean), np.log(tau_mean))
    return gd_true, float(n_global), n_local  # n_global para relatório
Benefício extra: n'(γ̇) pode ser exibido como tabela no relatório, revelando regiões de transição comportamental do fluido.

M6 — AIC/BIC para Seleção do Melhor Modelo
Problema: R² favorece HB (3 params) vs PL (2 params) mesmo quando τ₀ é desnecessário.
def calc_aic_bic(n_pts, n_params, y_true, y_pred):
    sse = np.sum((y_true - y_pred)**2)
    aic = n_pts * np.log(sse / n_pts) + 2 * n_params
    bic = n_pts * np.log(sse / n_pts) + n_params * np.log(n_pts)
    return aic, bic
# Menor AIC/BIC = melhor modelo
# ΔAIC > 2: evidência moderada; ΔAIC > 10: evidência forte
Recomendação: usar AIC como critério de seleção automática (substituindo R²) e exibir AIC, BIC e R² ajustado na tabela de modelos dos relatórios.
M7 — Intervalo de Confiança dos Parâmetros
curve_fit retorna pcov (covariância), que atualmente não é utilizada. Para modelos não-lineares com poucos pontos, complementar com bootstrap paramétrico:
# Método 1 — pcov (rápido, assume gaussianidade local)
popt, pcov = curve_fit(func, gd, tau, ...)
perr = np.sqrt(np.diag(pcov))       # desvio-padrão dos parâmetros
ic95 = 1.96 * perr                  # IC 95%
# Método 2 — bootstrap (mais robusto para n < 10 pontos)
boot_params = []
for _ in range(500):
    tau_b = tau_mean + np.random.normal(0, tau_std)
    tau_b = np.maximum(tau_b, 1e-9)
    try:
        p, _ = curve_fit(func, gd, tau_b, p0=popt, maxfev=2000)
        boot_params.append(p)
    except: pass
ic_low  = np.percentile(boot_params, 2.5, axis=0)
ic_high = np.percentile(boot_params, 97.5, axis=0)
# Exibir: K = 28,5 ± 3,2  (IC 95%) | n = 0,41 ± 0,04
M8 — WLS (Mínimos Quadrados Ponderados) no Ajuste
Problema: o OLS atual trata todos os grupos como igualmente confiáveis. Grupos com alta dispersão (típico em altas taxas) recebem o mesmo peso que grupos precisos.
# Proteção: grupos com 1 repetição têm std=0 → usar 5% como mínimo
sigma_safe = np.where(tau_std < 1e-3, tau_mean * 0.05, tau_std)
popt, pcov = curve_fit(
    func_modelo, fit_gd, fit_tau,
    p0=p0, bounds=bounds,
    sigma=sigma_safe,
    absolute_sigma=True,
    maxfev=10000
)
M9 — Módulo de Validação por Fluido de Referência
Objetivo: verificar a cadeia completa de medição (sensor → cálculo → modelo) com um fluido de viscosidade conhecida. Diferente da calibração do sensor, que só verifica P → bar.
Fluidos sugeridos: glicerina ≥ 99% (η tabelada a cada temperatura na literatura; custo baixo) ou óleo de silicone com certificado de viscosidade (mais caro, porém rastreável).
Fluxo proposto na GUI:
Nova aba ou botão em 'Calibração': 'Verificação com Fluido Newtoniano'
Campos: viscosidade de referência (Pa·s), temperatura do ensaio (°C)
O software executa o pipeline normal e compara: η_medido vs η_referência
Saída: erro relativo (%), aviso se > 5%, sugestão de recalibrar D ou sensor

M10 — Expor delta_p nos Relatórios
delta_p = p_linha − p_pasta é calculado e armazenado mas nunca exibido. Tem valor diagnóstico: delta_p crescente indica entupimento progressivo ou desgaste mecânico. Adicionar como coluna na tabela de dados brutos do relatório PDF.

M12 — Aviso quando Número de Bins < 4

M13 — Melhorar Estimativa Inicial do Modelo HB
Problema: guess_hb retorna [min(τ)*0,5, 1,0, 0,5] — estimativa genérica que pode convergir para mínimo local.
def guess_hb(gd, tau):
    tau0_guess = max(0, np.min(tau) * 0.5)
    tau_red = np.maximum(tau - tau0_guess, 1e-9)
    try:
        s, i, *_ = linregress(np.log(gd), np.log(tau_red))
        return [tau0_guess, np.exp(i), s]
    except:
        return [tau0_guess, 1.0, 0.5]

23. Motivação e Estrutura
Os gráficos gerados durante as análises deste relatório (análise de dados do MCR102, curvas de ajuste, comparativos entre ensaios) foram produzidos com um conjunto coeso de configurações matplotlib que resultou em visualizações de alta qualidade. Este módulo formaliza essas configurações como um arquivo reologia_plot_style.py reutilizável, pronto para ser integrado diretamente ao app do reômetro capilar (customtkinter + FigureCanvasTkAgg).
O módulo está organizado em seis seções:
Seção 1 — Paleta de cores e dicionário STYLE centralizado
Seção 2 — apply_dark_style(): tema escuro via rcParams (uma chamada na inicialização do app)
Seção 3 — Helpers de criação de figura: make_figure(), make_subplots(), make_gridspec_figure()
Seção 4 — Funções de plotagem prontas: plot_flow_curve(), plot_viscosity(), plot_nprime(), plot_bagley(), plot_mooney(), plot_overlay(), add_model_annotation()
Seção 5 — Integração com customtkinter: embed_figure(), update_canvas()
Seção 6 — Demo executável (python reologia_plot_style.py)

        self.fig, self.axes = rps.make_subplots(ncols=2, figsize=(13, 5))
        self.canvas = rps.embed_figure(self.fig, self)
        self.canvas.get_tk_widget().pack(fill='both', expand=True)
    def atualizar_graficos(self, gd, tau, tau_std, gd_fit, tau_melhor,
                           extra_fits, params):
        ax_log, ax_eta = self.axes
        # Limpar e re-estilizar eixos
        ax_log.clear()
        ax_eta.clear()
        rps._style_axes(ax_log)
        rps._style_axes(ax_eta)
        # Curva de fluxo log-log
        rps.plot_flow_curve(
            ax_log, gd=gd, tau=tau, tau_std=tau_std,
            gd_fit=gd_fit, tau_fit_best=tau_melhor,
            label_best=f'Modelo: {params["nome"]}  R²={params["r2"]:.4f}  ★',
            extra_fits=extra_fits,
            band_range=(50, 2000),
        )
        rps.add_model_annotation(ax_log, params)
        # Viscosidade
        rps.plot_viscosity(ax_eta, gd=gd, eta=tau/gd, eta_std=tau_std/gd)
        rps.update_canvas(self.canvas, self.fig)

30. Detalhes das Configurações que Fazem a Diferença
A seguir, as configurações específicas que mais contribuem para a qualidade visual dos gráficos gerados durante este projeto:
Configuração
Valor
Por que faz diferença
edgecolors nos scatter
"#1e1e2e" (mesma cor do fundo)
Cria contorno sutil nos pontos, separando-os visualmente sem poluir o gráfico — especialmente importante quando pontos se sobrepõem
s=60 + zorder=7
tamanho 60, camada 7
Pontos visíveis sem mascarar a curva de ajuste (zorder 9)
axvspan alpha=0.08
8% de opacidade
Região operacional visível sem distrair — mais que 15% domina o gráfico
grid which='both' alpha=0.7/0.4
major 0.70, minor 0.40
Grade major guia a leitura; minor facilita interpolação visual sem poluir
LogLocator subs=2..9
minor ticks em 2,3,4,...,9×
Em escala log, os minor ticks preenchem o espaço visual entre décadas corretamente
tight_layout(pad=1.5)
padding de 1.5 unidades
Evita corte de rótulos e títulos sem desperdiçar espaço — pad=1.0 costuma cortar, pad=2.0 desperdiça
legend labelspacing=0.35
espaçamento 0.35
Legendas compactas mas legíveis — padrão matplotlib (0.5) é espaçoso demais para gráficos pequenos
figsize=(9,6) dpi=110
proporcão 3:2 a 110 dpi
Proporcão próxima do áureo para gráficos de fluxo; 110 dpi é suficiente para tela sem ser pesado
bbox_inches='tight' ao salvar
sem margem extra
Remove espaço vazio na exportação; essencial para inserir em relatórios PDF

# ── Helpers de eixo ────────────────────────────────────────────────────
def _style_axes(ax):
    ax.set_facecolor(BG_AXES)
    for sp in ax.spines.values():
        sp.set_color(FG_SPINE); sp.set_linewidth(0.8)
    ax.tick_params(colors=FG_TICK, which='both', direction='out',
                   labelsize=9.5, length=4)
    ax.tick_params(which='minor', length=2.5)
    ax.xaxis.label.set_color(FG_TEXT)
    ax.yaxis.label.set_color(FG_TEXT)
    ax.title.set_color(FG_TEXT)
    ax.grid(**STYLE['grid_major'])
    ax.grid(which='minor', **STYLE['grid_minor'])
def _log_axes(ax, which='both'):
    if which in ('x','both'):
        ax.set_xscale('log')
        ax.xaxis.set_minor_locator(LogLocator(subs=np.arange(2,10)))
    if which in ('y','both'):
        ax.set_yscale('log')
        ax.yaxis.set_minor_locator(LogLocator(subs=np.arange(2,10)))
    ax.grid(**STYLE['grid_major'])
    ax.grid(which='minor', **STYLE['grid_minor'])
def make_figure(figsize=(9,6), dpi=110):
    fig, ax = plt.subplots(figsize=figsize, dpi=dpi)
    fig.patch.set_facecolor(BG_DARK)
    _style_axes(ax); return fig, ax
def make_subplots(nrows=1, ncols=2, figsize=None, dpi=110, **kw):
    if figsize is None: figsize = (8*ncols, 5.5*nrows)
    fig, axes = plt.subplots(nrows, ncols, figsize=figsize, dpi=dpi, **kw)
    fig.patch.set_facecolor(BG_DARK)
    for ax in np.array(axes).flat: _style_axes(ax)
    return fig, axes
def make_gridspec_figure(figsize=(16,10), dpi=110):
    fig = plt.figure(figsize=figsize, dpi=dpi)
    fig.patch.set_facecolor(BG_DARK)
    gs = gridspec.GridSpec(2, 3, figure=fig, hspace=0.38, wspace=0.32)
    axes = {
        'flow'     : fig.add_subplot(gs[0, :2]),
        'visc'     : fig.add_subplot(gs[0, 2]),
        'nprime'   : fig.add_subplot(gs[1, 0]),
        'residuals': fig.add_subplot(gs[1, 1]),
        'params'   : fig.add_subplot(gs[1, 2]),
    }
    for ax in axes.values(): _style_axes(ax)
    return fig, axes

def plot_flow_curve(ax, gd, tau, tau_std=None,
                    gd_fit=None, tau_fit_best=None, label_best='',
                    extra_fits=None, gd_ref=None, tau_ref=None,
                    label_ref='Referência', band_range=None,
                    log_log=True,
                    xlabel='Taxa de Cisalhamento \u03b3\u0307 (s\u207b\xb9)',
                    ylabel='Tens\xe3o de Cisalhamento \u03c4_w (Pa)',
                    title='Curva de Fluxo'):
    if band_range:
        ax.axvspan(band_range[0], band_range[1],
                   label='Faixa do capilar', **STYLE['band'])
    if gd_ref is not None:
        ax.scatter(gd_ref, tau_ref, label=label_ref,
                   **STYLE['scatter']['reference'])
    if tau_std is not None:
        ax.errorbar(gd, tau, yerr=tau_std, **STYLE['errorbar'])
    ax.scatter(gd, tau, label='Dados experimentais',
               **STYLE['scatter']['data'])
    line_keys = ['alt1','alt2','alt3']
    if extra_fits:
        for i,(gf,tf,lbl,*k) in enumerate(extra_fits):
            ax.plot(gf, tf, label=lbl,
                    **STYLE['line'][k[0] if k else line_keys[i%3]])
    if gd_fit is not None and tau_fit_best is not None:
        ax.plot(gd_fit, tau_fit_best, label=label_best,
                **STYLE['line']['best_fit'])
    if log_log: _log_axes(ax)
    ax.set_xlabel(xlabel, **STYLE['xlabel'])
    ax.set_ylabel(ylabel, **STYLE['ylabel'])
    ax.set_title(title, **STYLE['title'])
    ax.legend(loc='lower right', **STYLE['legend'])
def plot_viscosity(ax, gd, eta, eta_std=None, gd_ref=None, eta_ref=None,
                   label_ref='Referência', band_range=None,
                   title='Viscosidade Aparente'):
    if band_range: ax.axvspan(band_range[0], band_range[1], **STYLE['band'])
    if gd_ref is not None:
        ax.scatter(gd_ref, eta_ref, label=label_ref,
                   **STYLE['scatter']['reference'])
    if eta_std is not None:
        ax.errorbar(gd, eta, yerr=eta_std, **STYLE['errorbar'])
    ax.scatter(gd, eta, label='\u03b7 experimental', **STYLE['scatter']['data'])
    _log_axes(ax)
    ax.set_xlabel('Taxa de Cisalhamento \u03b3\u0307 (s\u207b\xb9)', **STYLE['xlabel'])
    ax.set_ylabel('Viscosidade \u03b7 (Pa\u00b7s)', **STYLE['ylabel'])
    ax.set_title(title, **STYLE['title'])
    ax.legend(**STYLE['legend'])
def plot_nprime(ax, gd_app, tau, n_prime_global=None):
    from scipy.stats import linregress
    valid = (gd_app > 0) & (tau > 0)
    lg, lt = np.log(gd_app[valid]), np.log(tau[valid])
    ax.scatter(lg, lt, label='ln(\u03c4) vs ln(\u03b3\u0307_app)',
               **STYLE['scatter']['data'])
    if n_prime_global:
        s, i, *_ = linregress(lg, lt)
        xl = np.linspace(lg.min(), lg.max(), 80)
        ax.plot(xl, s*xl+i, label=f"n' global = {s:.3f}",
                **STYLE['line']['best_fit'])
    ax.set_xlabel('ln(\u03b3\u0307_app)', **STYLE['xlabel'])
    ax.set_ylabel('ln(\u03c4_w)', **STYLE['ylabel'])
    ax.set_title('Determinação de n\' (W-R)', **STYLE['title'])
    ax.legend(**STYLE['legend'])
def plot_bagley(ax, L_over_D_list, P_list, slope, intercept,
                target_gamma_label=''):
    xa = np.array(sorted(L_over_D_list))
    ax.scatter(L_over_D_list, np.array(P_list)/1e5,
               label='Dados', **STYLE['scatter']['data'])
    ax.plot(xa, (slope*xa+intercept)/1e5,
            label=f'Ajuste  \u03c4_w={slope/2:.1f} Pa',
            **STYLE['line']['best_fit'])
    ax.set_xlabel('L/D', **STYLE['xlabel'])
    ax.set_ylabel('\u0394P (bar)', **STYLE['ylabel'])
    ax.set_title('Correção de Bagley' + (f'  |  \u03b3\u0307\u2248{target_gamma_label} s\u207b\xb9' if target_gamma_label else ''), **STYLE['title'])
    ax.legend(**STYLE['legend'])
def plot_mooney(ax, inv_R_list, gd_app_list, slope, intercept):
    xa = np.array(sorted(inv_R_list))
    ax.scatter(inv_R_list, gd_app_list, label='Dados', **STYLE['scatter']['data'])
    ax.plot(xa, slope*xa+intercept,
            label=f'\u03b3\u0307_true={intercept:.1f} s\u207b\xb9  V_slip={slope/4:.4f} m/s',
            **STYLE['line']['best_fit'])
    ax.set_xlabel('1/R (m\u207b\xb9)', **STYLE['xlabel'])
    ax.set_ylabel('\u03b3\u0307_app (s\u207b\xb9)', **STYLE['ylabel'])
    ax.set_title('Correção de Mooney (Wall Slip)', **STYLE['title'])
    ax.legend(**STYLE['legend'])
def plot_overlay(ax, datasets, log_log=True, band_range=None,
                 title='Comparativo'):
    cyc = [PALETTE[k] for k in ('data','fit','alt1','alt2','alt3','ref')]
    if band_range: ax.axvspan(band_range[0], band_range[1], **STYLE['band'])
    for i, ds in enumerate(datasets):
        c = ds.get('color', cyc[i % len(cyc)])
        ax.scatter(ds['gd'], ds['tau'], label=ds.get('label',f'#{i+1}'),
                   **{**STYLE['scatter']['data'], 'color': c})
        if 'tau_std' in ds:
            ax.errorbar(ds['gd'], ds['tau'], yerr=ds['tau_std'],
                        **{**STYLE['errorbar'], 'color': c})
        if 'gd_fit' in ds and 'tau_fit' in ds:
            ax.plot(ds['gd_fit'], ds['tau_fit'],
                    **{**STYLE['line']['best_fit'], 'color': c})
    if log_log: _log_axes(ax)
    ax.set_xlabel('Taxa de Cisalhamento \u03b3\u0307 (s\u207b\xb9)', **STYLE['xlabel'])
    ax.set_ylabel('Tens\xe3o de Cisalhamento \u03c4_w (Pa)', **STYLE['ylabel'])
    ax.set_title(title, **STYLE['title'])
    ax.legend(**STYLE['legend'])
def add_model_annotation(ax, params_dict, position='lower right'):
    text = '\n'.join(f'{k} = {v}' for k,v in params_dict.items())
    lm = {'lower right':(0.97,0.04,'right','bottom'),
          'upper left' :(0.03,0.96,'left','top'),
          'upper right':(0.97,0.96,'right','top'),
          'lower left' :(0.03,0.04,'left','bottom')}
    x,y,ha,va = lm.get(position, lm['lower right'])
    ax.text(x, y, text, transform=ax.transAxes, ha=ha, va=va,
            bbox=STYLE['annotation_box'], **STYLE['annotation_text'])
